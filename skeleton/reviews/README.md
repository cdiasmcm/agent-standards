# Reviews

Audit reports and feedback on the standard for **this agent** live here, never in the agent-standards
framework (which is read-only).

- `standards-audit-YYYY-MM-DD.md`: output of the Audit workflow (`deploy/audit-agent.ps1` + the advisor's judgment review)
- `standards-feedback-YYYY-MM-DD.md`: proposals to improve the standard (Improve workflow). The framework maintainer decides
