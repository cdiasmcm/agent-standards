# Decisions — design-time human decisions

Architecture choices, splits into more agents (with the reason and evidence), the model choice and why,
every change of autonomy level (dry run → draft → execute), accepted risks. `AGENT.md` holds the current
setting; this file holds why it is that way. Append-only: never edit an old entry; add a new one that
supersedes it.
Runtime human decisions (approvals, rejections, edits) go to the human-decision log (`AGENT.md` §8),
not here.

Format: `- YYYY-MM-DD — decision — why — who`
